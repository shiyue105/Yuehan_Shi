## Transformations (explicitly disclosed)

1. **Publication venue full names** — the CV uses abbreviations "ACML 2026" and
   "PRCV 2026". The site expands them to their standard full names
   ("Asian Conference on Machine Learning", "Chinese Conference on Pattern
   Recognition and Computer Vision"). No locations or dates were added.
2. **CCF-C labels** — copied as printed on the CV; displayed as a separate badge.
3. **Chinese translation** — a faithful translation of the English copy. The name
   is kept as "Yuehan Shi" (the CV does not provide Chinese name characters).
   Supervisor names are kept in Latin script for the same reason.
4. **Update dates** — items derived from CV month/year ranges (e.g., "Jul 2026").
   Acceptance-related updates are dated "2026" only, because the CV does not state
   acceptance months.

## Deliberately excluded

- **Personal phone number** (present in the source CV; digits intentionally omitted
  here as well) — private; never published in any repository file.
- **The CV PDF itself** — not committed to the repository.
- **Headshot / portrait** — none exists with permission to publish; the site uses a
  typographic monogram instead.
- **DOIs, arXiv links, paper PDFs, Google Scholar / ORCID / DBLP / LinkedIn profiles** —
  none are verifiable from the CV; fabricating them is prohibited. The only external
  links on the site are the GitHub profile and `mailto:` email.
- **Publication locations, acceptance dates, presentation formats** (oral/poster),
  citation metrics, rankings beyond CCF-C — not stated in the CV.
- **Any link for the two accepted papers, the OLAR submission, or the RC-TTD
  manuscript** — links render only when a real, owner-confirmed URL exists.
